Server

Welcome to the Item Management System. This server provides CRUD operations for managing items.

Available Endpoints

  • GET /items - Get all items
  • GET /items?id=1 - Get item by ID
  • GET /items/1 - Get item by ID (RESTful)
  • POST /items - Create new item
  • PUT /items - Update existing item
  • DELETE /items?id=1 - Delete item by ID
  • DELETE /items/1 - Delete item by ID (RESTful)
